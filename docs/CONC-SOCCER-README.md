# ConC Soccer — website preview

This static preview is stored in `docs/` so it does not replace the existing PitchPredict backend.

## Publish with GitHub Pages (free)
1. Open repository Settings → Pages.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch `main` and folder `/docs`, then Save.
4. Wait for GitHub Pages to publish the site.

## Important
The fixture cards and percentages are illustrative demo content, not live fixtures or betting tips. Live worldwide fixtures, licensed source data, automated settlement and the complete consensus backend still need to be connected. Do not expose API keys in browser code.
